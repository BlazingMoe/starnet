THE STATION

// the layout you draw is the workflow they run

Placed gear is real capability

Props aren't decoration. A signal dish grants web access, a cabinet grants files, a workbench grants a terminal — and so on across the catalog. Gear is station-shared: place a thing once and your whole crew can draw on it. You don't need to duplicate props room by room. Removing a prop revokes the capability on the very next run — the floor is the permission surface, no config files.

Bays are concurrency

Each bay you place hosts another agent running its own genuinely separate, bounded runs at the same time. A bay needs its own PC to run — and the station tells you honestly when one can't ("NO COMPUTE — ADD A PC") instead of pretending.

Build mode

Open build mode to lay floors, raise walls, cut doorways, and place props. The station is yours from minute one: there is no unlock tree, no gated progression, no grind. Full power immediately; the game layer is presentation, never permission.

Workstations

Every agent has a home desk — chosen when the agent is created. When a run uses a tool, the agent physically walks to the workstation that grants it. That trip is driven by the real tool call in the run, which is why watching the floor tells you what's actually happening.

Truthful telemetry

The core law of the whole product: the app never asserts state the harness can't prove. No fake progress bars, no idle animations pretending to be work, no "agents online" counters that aren't real. If the station shows an agent at a desk mid-run, there is a live run behind it; when you see nothing happening, nothing is happening. This is what makes the window worth glancing at.
