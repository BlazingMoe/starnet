HOW CONVEYORS WORK

Your floor is a flowchart. Every crate on it is a real job.

LEVEL ●●●~8 MINNEEDS: 1 AGENTBUILDS: A LIVE WORK LINE
// THE ONE LAWBelts never spawn decorative cargo. A crate exists only because something real entered the station. Still floor = no work. Moving crate = you are paying for a run.

01The parts

INBOX
2 × 2
The front door. Outside work drops onto the belt here.
BAY
2 × 2
One agent’s dock. A crate landing here starts their run.
OUTBOX
2 × 2
The dispatch chute. Finished replies leave the station.
JUNCTIONS
1 × 1
FILTER, SPLITTER, JOINER, LOOP — they sit on the belt.
// YOU DON’T NEED AN INBOXA BAY alone is enough for an agent to work, and COMMS orders land straight there. The INBOX is for work arriving from outside.

02Build one

  1. Drop the machines

    Hit REFIT STATION, take PROP 6 and place an INBOX, a BAY and an OUTBOX in a rough row. Leave a few tiles of clear deck between them — that gap is where the belt goes.

    machines down, gaps left for belt
  2. Two clicks per link

    Take BELT 7 and click one machine, then the next. The belt lays itself, corners and all. Legal endpoints glow while the tool is armed: the INBOX as a from, bays and the outbox as a to.

    BELT tool: two clicks per link
  3. Crew the bay

    Click the BAY and bind an agent. The moment a route reaches a crewed bay the whole run lights up — that glow is the compiler telling you the wiring is valid.

    a bound bay energizes the run
  4. Set what it may spend

    Click the INBOX to name the line and set its LINE BUDGET. Left blank you get the station defaults: 6 hops and $2.00 per message, no daily cap.

    the INBOX card holds the caps
  5. Feed it real work

    Leave REFIT and send the line a job — a DM through a connected channel, or a routine firing. A crate leaves the INBOX, rides to the bay and sinks. That agent is now running.

    a real crate = a real run
// SKIP THE FIRST TEN MINUTESThe LINES tool 9 stamps a whole pre-wired layout in one click. See Your First Working Line.

03Read the floor

You never have to guess whether a line is wired right. StarNet recompiles the belt graph on every edit and renders the answer onto the tiles.

ENERGIZED

The route reaches a crewed bay. Treads march, the drive LED blinks, crates ride.

COLD

Same belts, no bound agent at the end. Treads frozen, LED dark, whole run dimmed.

// CLASSIC GOTCHAA belt that only touches a junction’s corner feeds nothing. The lane has to run through the junction tile — in one side, out the other. This is the single most common cause of a bay reporting NOT FED.

04Four shapes that do everything

HAND-OFFCHAIN

A dock’s output is the next dock’s input. Agent A researches, agent B writes from A’s brief, and the reply that leaves is B’s.

SORTFILTER

The filter reads each unaddressed job and picks a lane by its content tag. Work already addressed to an agent rides straight past it.

PARALLELSPLITTER

One stream fanned across three agents working at once. One crate in is one run out — the floor never quietly absorbs work.

GO ROUND AGAINLOOP

Draft → critique → redraft, bounded. The only legal cycle: five passes by default, twenty at most, all inside the line’s dollar cap.

// THE EXPENSIVE ONETwo bays that ship into each other are a work-line loop. No belt cycle exists — each lane is ordinary — but the work would run forever, paying every lap. The compiler refuses it outright.
// A BROKEN STAGE NEVER EATS THE ANSWERHop cap, dollar cap, a failed stage, E-STOP — every stop still delivers the last good output plus a note naming exactly where the line stopped.

05When it won’t run

These are the exact labels the floor shows, and each one names its own fix. They appear before anything is billed.

NO AGENT — CLICK

A bay with nobody bound to it. Click the bay and pick an agent.

NOT ON THE LINE

The bay has no belt touching it at all. It is furniture until you connect it.

NOT FED

Belts exist but no route reaches this bay — usually a lane clipping a junction’s corner instead of running through its tile.

NOT CONNECTED

An INBOX with no belt out. Arm BELT 7, click the inbox, then click a bay.

DUP AGENT — ONE BAY EACH

Two bays bound to the same agent. One desk per agent.

A PROP SITS ON THIS LINE — MOVE IT

Furniture was placed over a belt tile. Move the prop, not the belt.

SPLITTER NEEDS 2 OUT-LANES

A splitter with one exit is just a belt tile. Run belts through it: in one side, out two.

JOINER NEEDS 2 IN-LANES

A joiner waits for branches to converge. With one branch there is nothing to wait for.

NO DEFAULT LANE — CLICK

A filter with no fallback. Work is never dropped — it falls back to the first lane — but set the default so you decide where.

LOOP! — BREAK THE CIRCLE

Your belts form a physical ring. A crate would ride forever. Add a LOOP gate, or cut a tile.

WORK LINE LOOPS — CUT ONE HANDOFF

No belt ring, but two docks feed each other. An infinite chain of paid runs.

LOOP HAS NO DONE / BACK LANE

A loop gate needs both exits: one carrying finished work onward, one running back to an earlier bay.

// UNDO IS FREEDELETE 5 removes a room, prop or belt tile — drag it across a run to clear the lot. Every edit is undoable, so experiment on the floor instead of theorising about it.

06Common questions

Do I have to build belts at all?

No. A bay with an agent bound to it works fine alone, and anything you ask for in COMMS goes straight there. Belts are how outside work finds its way in, and how one agent’s output becomes another’s input.

Why is my belt dark even though it is connected?

Because the route does not end at a crewed bay. Follow the run to its end — you will find an unbound bay, a gap, or a lane passing a junction’s corner.

Can two lines share one bay?

Several lanes can converge on the same dock — crates queue rather than collide. What you cannot do is bind one agent to two different bays.

What stops a long chain running up a huge bill?

Every line carries a hop cap and a per-message dollar cap — 6 hops and $2.00 by default, set on the INBOX, hard-ceilinged at 24 hops and $50. When a cap is reached the line stops and delivers what it has, with a note saying so.

Do crates keep moving when I am not watching?

The work does. A crate is a view of a real run — the harness executes it whether or not the station is on screen, and the floor catches up when you look.
